
# E-Commerce Sales & Customer Analysis (SQL)

## Overview
SQL-based analysis of e-commerce customer and sales records to identify customer and product-related insights.

## SQL Concepts Used
- **Joins:** Retrieving and combining data from multiple tables
- **Grouping & Filtering:** `GROUP BY` and `HAVING` to analyse sales data
- **Aggregate Functions:** `SUM()` and `COUNT()` for sales analysis
- **Subqueries:** Identifying customer and product-related insights

## Key Analysis
- Analysing customer and sales records across related tables
- Summarising sales using `SUM()` and `COUNT()` with `GROUP BY` and `HAVING`
- Finding customer and product insights through subqueries

## Repository Files
- `schema.sql` – Table structures and keys
- `data.sql` – Sample records
- `queries.sql` – SQL queries for sales and customer analysis
